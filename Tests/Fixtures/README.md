The executable's SimulationFixtures.swift contains seven semantic scenarios. TestHarness.swift adds provider-outage, recurring-topic and sixty-minute resource checks, plus PKCE/JWT, stream, export and pipeline checks. major-revelation.json is an editable external example. GUI offline replay uses the compiled fixture; GUI live replay submits its synthetic messages to the configured real text provider. Offline validation does not certify model behavior.

MemoryFixtures.swift and Memory-demo-export.json provide a synthetic ChatGPT export with alternate branches, a later correction, listening observations, source references, multimedia metadata and long messages. MemoryTests.swift runs 69 isolated SQLite/import/retrieval checks. MemoryLiveTest.swift explicitly sends only a temporary synthetic archive to the existing selected provider. No personal chat history is bundled.
